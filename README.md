# Smart Calculator App

A simple Calculator Android App built using Kotlin and Jetpack Compose.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Input validation
- Modern UI

## Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
